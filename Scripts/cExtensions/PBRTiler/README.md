# PBRTiler Extension for 3DCoat

PBRTiler is an extension for 3DCoat and 3DCoat Textura that provides a convenient graphical user interface for seamless tiling of PBR textures. The tool uses PySide6 to create the user interface and OpenGL for display and rendering.

## Installation

To install the extension, you need to extract the `PBRTiler` folder into your program's scripts directory.

- **For 3DCoat:**
  Copy the `PBRTiler` folder to the following path:
  `Documents\3DCoat2026\UserPrefs\Scripts\cExtensions\PBRTiler`

- **For 3DCoat Textura:**
  Copy the `PBRTiler` folder to the following path:
  `Documents\3DCoatTextura\UserPrefs\Scripts\cExtensions\PBRTiler`

Restart 3DCoat after copying.

## Usage

1. Launch 3DCoat or 3DCoat Textura.
2. In the top menu of the program, navigate to the **Scripts** section.
3. Click on **OpenPBRTiler** to open the main extension window.

## Requirements
- 3DCoat 2026 (or 3DCoat Textura)
- PySide6 support (usually built-in in new versions of 3DCoat; required dependencies are installed automatically by 3DCoat).
